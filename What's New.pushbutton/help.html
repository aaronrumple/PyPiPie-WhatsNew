Using What's New

Normal click

Use a normal click when you want to see what has been added since the last time you checked.

  • First normal run: shows every installed production-ready feature.
  • Later normal runs: shows only features that have never been shown before.
  • If there are no newly added features, the page displays Nothing new.

Shift + click

Use Shift-click whenever you want to browse the complete installed feature catalog.

  • Always shows the full feature set.
  • Does not change which features have been recorded as seen.
  • Runs through pyRevit's optional config.py action.
1. DiscoverFind folders containing help.html.

What counts as a feature?

What's New treats a feature as production ready when its folder contains a help.html file. Folders without help.html are not included in the catalog.

The feature is tracked by a normalized ID based on its folder path relative to the extension root. Once that ID has been shown during a normal run, it is considered seen for that user.

Important: editing an existing feature's help.html does not make that feature new again. The current implementation tracks newly added feature IDs, not help-file content changes.

If a title ends with - Help, – Help, or — Help, that suffix is removed in What's New so the card displays only the feature name.

Supported feature icon names

The feature folder is checked in this order:

icon.png, icon.dark.png, icon.svg, icon.jpg, icon.jpeg.

PyPiPie feature icons are typically created at 64×64 px. What's New displays them at 48×48 px on each feature card.

Feature history

Normal runs keep a per-user list of feature IDs that have already been displayed. The current state file is:

%APPDATA%\PyPiPie\WhatsNew\state.json

The file contains an initialization flag, the normalized feature IDs already seen by that user, and the last-run time. Writes are performed through a temporary file and then verified by reading the saved data back.

State rules

  • The first successful normal run records all currently discovered features.
  • A later normal run shows only IDs not present in the saved history.
  • A normal run with no new IDs shows Nothing new.
  • Shift-click is read-only and does not update the state file.
  • Older state formats are treated as migration sources when present.
Resetting What's New: deleting the user's state.json makes the next normal execution behave as a first run and show the entire installed feature set again.

What's New pushbutton bundle

The command depends on pyRevit's normal script/config separation. Keep the main script and Shift-click configuration script distinct.

What's New.pushbutton\
    WhatsNew_script.py     # normal click / main command
    config.py              # Shift-click action
    Welcome.xaml           # loading dialog
    PyPiPie_Logo.png       # loading + output branding
    icon.png               # pyRevit ribbon icon, if used
    bundle.yaml            # bundle metadata, if used
    help.html              # this help page
Do not add another *script.py command file to this bundle. pyRevit selects a matching script as the bundle's main command; competing script filenames can cause the wrong file to execute. The optional Shift-click action belongs in config.py.

config.py loads the shared implementation from WhatsNew_script.py without allowing its normal auto-run, then explicitly calls main(True). A normal pyRevit execution of WhatsNew_script.py calls main(False).

Troubleshooting

SymptomCheck
Every normal click shows the full catalog.Confirm the bundle contains one main *script.py file and the Shift-click file is named config.py. Reload pyRevit after changing bundle filenames.
Footer says Mode: Shift catalog on a normal click.The config action is being executed as the main command. Check the bundle filenames first.
Second normal run still shows everything.Check that %APPDATA%\PyPiPie\WhatsNew\state.json exists and that the generated footer reports a nonzero seen count and a successful state save/verification.
No loading dialog.Confirm Welcome.xaml is beside the main script and includes StatusText, PercentText, LoadProgress, and LogoImage.
Loading dialog has no PyPiPie branding.Confirm PyPiPie_Logo.png is in the command folder. The script can fall back to local button icon files if the branding image is unavailable.

A feature name includes “Help”.Only a trailing dash + “Help” is automatically removed. Review the feature's <title> value.
Feature icon is missing.Use one of the supported icon filenames in the same folder as that feature's help.html.

Limitations

  • Feature readiness is determined solely by the presence of help.html.
  • The current notification logic detects newly added feature IDs; it does not announce revisions to an existing feature.
  • The tool scans its containing extension and any additional roots explicitly added in EXTRA_ROOTS.
  • Generated catalog pages are temporary local HTML files. Each run uses a unique filename so an already-open browser tab cannot display stale results.
  • The What's New command folder itself is excluded from discovery so this help page does not cause the utility to list itself.
